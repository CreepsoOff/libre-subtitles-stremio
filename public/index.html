Libre Subtitles for Stremio

Install the add-on that aggregates subtitles from libre-subs.fifthwit.net and shape the languages, formats, and sources you want to expose inside Stremio.

⚙️ Quick install

  1. Start the local server with npm start (default port: 7000).
  2. Open Stremio → Addons → Community Addons.
  3. Generate your personalised link below, then click “Install in Stremio”.
